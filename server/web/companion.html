Model choices and usage

GPT-6 Astra: the default here. OpenAI describes it as its highest-capability model for demanding work.

GPT-5.6 Sol: an alternative for complex work with lower published API rates. A lower price does not mean a faster response.

Both have a published 1,050,000-token context limit. Barista sends a bounded conversation, not the whole desktop.

Standard API rates per million tokens, checked 20 October 2026: Astra $10 input / $50 output; Sol $4 input / $20 output. These are not Codex subscription charges. Cache, long-context, and service-tier rates differ.

Your signed-in backend controls access, usage, and charges. This control does not enable Fast mode or change provider settings. No automatic model fallback.

Exact cursor requests use local Accessibility lookup without a model. Conversation names do not change the model.

Sources: Astra specifications · Sol specifications

Tap ⌃⌥Space to toggle. Hold it to talk. Escape dismisses; it does not stop an agent turn.

Voice uses on-device recognition and an installed system voice. New speech interrupts playback.

Questions and requested app text go to your assistant provider. Drawing and the demo are local. No automatic screenshots.
